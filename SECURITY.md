# Security Policy

## Supported Versions

We release patches and security updates for the current version:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The project takes security seriously. If you discover a security vulnerability in **Fame Fighters (Sansad Showdown)**, please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Email the maintainer directly at **[ayush_24a12res897@iitp.ac.in](mailto:ayush_24a12res897@iitp.ac.in)**.
3. Include detailed steps to reproduce the vulnerability, along with proof of concept if available.
4. Allow reasonable time for the maintainer to investigate and patch the issue before any public disclosure.

You will receive an initial response within 48 hours acknowledging receipt of your report. Thank you for helping keep this project secure!
